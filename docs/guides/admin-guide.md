# 管理员使用指南

管理员拥有平台全部权限：用户/部门/标签管理、文档库与审批、AI 提示词、题库、学习资料、视频、试卷、备份。

## 登录与首页

1. 打开平台地址，使用管理员账号登录。
2. 登录后进入「工作台」，展示平台概况（文档/题库/学习资料/试卷数量、最近考试等）。

## 组织与人员

### 部门管理（部门管理）
- 新建/编辑/删除部门。删除有用户的部门会被拒绝。

### 用户管理（人员管理）
- 创建用户（用户名/邮箱/手机号/部门/角色/密码），搜索、按角色筛选、排序。
- 修改角色（仅管理员）、重置密码、删除用户。
- 为学员打标签（见「学员标签」）。

### 学员标签（学员标签）
- 创建标签，并给学员分配/移除标签。标签用于考试批次按人群安排。

## 文档与审批

### 文档库管理（文档库管理）
- 新建文档库，上传文档（支持 txt/md/pdf/docx/xlsx/xls/pptx）。
- 上传的文档进入「文档审批」暂存区。

### 文档审批（文档审批）
- 对暂存文档执行语义检查、内容审核（AI 改写）、预览，确认后入库。
- 确认前可选择「新增」或「替换」已有文档，避免重名冲突。

### 备份（文档库 → 备份）
- 备份整个文档库（ZIP，按内容 SHA256 去重），查看备份文档、恢复备份。

## AI 提示词

- 三类提示词：改写（rewrite）、学习资料（study）、出题（exam），每类同名字唯一。
- 提示词影响学习资料/题库的生成风格。

## 内容生成

### 题库管理（题库管理）
- 选择文档库 → 选择提示词 → AI 异步生成题库（轮询进度）。
- 查看试卷（题目清单）、编辑、禁用（禁用后学生模拟训练不再显示）、删除。

### 学习资料（学习资料）
- 选择文档库 → 文档 → 提示词 → 生成结构化学习材料（封面/章节/页面，含 CSS 样式）。
- 支持 TTS 配音（选择配音角色）。
- 「统计」查看：看过学生数、完成学生数、总打开次数、平均/总观看时长，以及每个学生的阅读情况。

### 视频资料（视频资料）
- 两种来源：本地上传（上传到 OSS）或从 OSS 已有文件建立记录。
- 列表显示创建时间；「统计」查看观看人数/次数/时长与留言；删除可同时移除 OSS 文件。

### 试卷管理（试卷管理）
- 选择题库、题型、题量/分值 → 校验（总分 100、题量匹配）→ 生成试卷。
- 创建考试批次，按学员或标签安排，设置时间与时长。
- 查看考试结果、逐题正确率、导出 HTML 报告。

## 常见问题

- 生成失败提示「AI 调用失败，请稍后再试」：AI 服务偶发，重新生成即可。
- 页面刷新跳转或 404：确认 OSS 桶的错误页（默认 404 页）设置为 `200.html`。
