# 教师使用指南

教师可管理学员、生成学习资料/题库/试卷并安排学习与考试；不能修改角色、删除管理员。

## 登录与首页

- 登录后进入「工作台」，展示教学概况与最近考试。

## 学员管理

- 「人员管理」查看学员、按部门/标签筛选；创建学员、重置密码、删除学员。
- 教师不能修改用户角色（该操作仅管理员可见）。

## 内容准备

### 题库（题库管理）
- 从文档库生成题库（异步，轮询进度），查看题目、禁用不再使用的题库。

### 学习资料（学习资料）
- 从文档库生成学习材料，可配音；「统计」查看学员学习情况。

### 视频（视频资料）
- 上传视频或引用 OSS 已有文件；查看观看统计与留言。

### 试卷（试卷管理）
- 生成试卷、创建考试批次、安排学员（按学员或标签）、查看成绩与逐题正确率、导出报告。

## 教学安排

- 学习资料、视频、模拟训练对学生端立即可见（学生进入「我的课程/我的学习视频/模拟训练」）。
- 考试需通过「考试批次」安排到具体学员后，学员才能在「我的考试」中作答。

## 说明

- 教师无权访问「部门管理」「学员标签」「AI 提示词」等仅管理员功能（侧边栏不显示）。
- 若发现侧边栏某项点击后跳回工作台，通常表示该功能超出教师权限。
